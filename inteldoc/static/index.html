THE FICTIONAL WORLD

World bible

Six invented factions. Seventeen reporting years. Real geography. One reproducible ground truth.

DRAFT / UNREVIEWED · Every organization, person, nickname, company, vessel, registration and operation name is invented. Only the geography is real. The starter name blocklist is not exhaustive. Review the seed before external distribution or paid generation.

Factions and arcs

Hand-authored in world/seed.yaml. Leadership windows marked Secret only appear solely in S//NF reporting, which is why the same question answers differently per persona.

Plazas and routes

Every corridor is a real place or route whose control changes hands on dated windows. These windows are controls edges in the graph.

How the graph is built

Edge types: participated_in, linked_to, occurred_at, transited, supported, involved_in, uses, leads, member_of, controls, owns, nominee_for, allied_with, split_from, arrested_in, killed_in, extradited_in, released_in, elected_in, removed_in, paid_in, designated_in. Windowed edges carry from/until dates. Shared nicknames belong to exactly two people and five nicknames are inherited when a boss falls; both are deliberate alias-resolution traps.

Every cable samples one event and the agency's partial view of it. About five percent of cables carry a deliberately conflicting date and one to two percent correct an earlier DocumentID. The scorecard reports those separately from extraction errors.

Source files: world/seed.yaml · world/expanded.json · world/graph_truth.json · docs/world-bible.md

Scope: synthetic data only; no production authentication. Model-assisted rendering, constrained extraction and quote-grounded answers are enabled by server configuration.
