World-first generation

Every cable is sampled from a seeded event model. The narrative renderer receives only the facts selected for that record, and the XML metadata is computed from the typed record.

Source files: world/seed.yaml · world/expanded.json · world/graph_truth.json

The offline baseline includes 200 fictional people, 80 front companies, 45 assets, 360 deliberately non-operational identifiers, 50 sources, 25 real places, and 600 events. Shared aliases are deliberate disambiguation cases.

Scope: no live API calls, no real intelligence, no production authentication. Contradiction/correction sampling, free-form LLM extraction, and a native desktop wrapper remain future work.
